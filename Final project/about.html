Про проект

Neon Defender — це фінальний проєкт з JavaScript.

HTML

Кілька сторінок, навігація, кнопки, canvas і форми.

CSS

Адаптивний дизайн, анімації, ефекти при наведенні та неоновий дизайн.

JavaScript

Логіка гри, зіткнення, очки, життя, рівні та комп’ютер.

Canvas

Космічний корабель, метеори та зірки намальовані за допомогою canvas.
